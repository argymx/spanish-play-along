Spanish Play Along

Reading aloud and pronunciation practice. You hear a phrase, say it back, then hear both and find out which sounds to fix.

Nothing leaves this device Checking voices… Microphone not yet allowed

How to use it

1Pick a passageOr a sound drill, if one sound keeps catching you out.
2Press StartA Spanish voice reads the first phrase, slowly if you want.
3Speak in the silenceIt leaves a gap the same length. Say the phrase into it.
4Compare and fixHear yourself against the model, tick what missed, read the advice.

It waits for you after every phrase. Press Next when you are ready, or flip the switch to Auto to let it run straight through.

    Your own passage, or a native speaker's voice
    
    
      
    Under step 1, open Use your own passage instead. Drop in a Word file, a PDF or text, or paste Spanish straight in. It is read in your browser and never uploaded, split into phrases at the punctuation, and the sounds in each phrase are tagged automatically so the advice still works. English translations are only shown for the built in passages, since nothing here can translate your own text offline.
    
      
    The model voice is whichever Spanish voice is on the device. To use a real person instead, open a phrase's ⋯ menu and choose Use my own model audio. Attached audio slows down without changing pitch, so it still sounds like someone speaking slowly.
    
    
    
  
    
  
    
    If recording does not work
    
    
      
    Press Test microphone at the top. It runs a full check and names the problem.
    
      
    On an iPhone or iPad there is a Safari fault: it mutes a microphone that is already open as soon as the page speaks, and the track can never be unmuted. This page works around it by taking a fresh microphone after the model has finished rather than holding one open. Whether that is enough depends on your iOS version, so run Test microphone, which speaks and then records to check the exact case that fails. If it still comes back silent, record in Voice Memos and use Attach clip on the phrase.
    
      
    Elsewhere the usual causes are a page opened straight from disk with a file:// address, a page inside an embedded frame, or a permission already set to denied, in which case the browser never prompts again. A desktop Mac also has no microphone of its own.
    
    
    
  
    
  
    
    For teachers
    
    
      
    This is rehearsal software, not assessment software. It gives a model, a controllable tempo, a silence to speak into, unlimited repetition and an immediate comparison. It never scores pronunciation, because automated scoring is least reliable on exactly the features that matter most here, and a wrong score teaches the wrong thing.
    
      
    The only measured feedback is timing: whether sound was present, when it started, how long it lasted. That cannot be wrong. Everything about the sounds is a self check, with a specific explanation and a drill attached.
    
      
    Nothing leaves the device. No audio, text or recording is uploaded or stored, there are no accounts and no analytics, so there is nothing for a data protection assessment to consider.
    
      
    Each set has its own link, so a single passage or drill can be set as homework. Use Copy link to this set.
